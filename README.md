# Connaissances de l'univers

Site de vulgarisation scientifique sur le système solaire, les étoiles et galaxies, et la cosmologie.
Angular 22, contenu rédigé en Markdown dans `contenu/`, converti et prérendu au build.

```bash
npm install
npm start        # http://localhost:4200
npm test
npm run build
```

Conventions de rédaction, architecture et décisions : voir [CLAUDE.md](CLAUDE.md).
